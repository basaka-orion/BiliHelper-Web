# BiliHelper · 视频学习工作台

把一节教程整理成有依据、可保存、下次能继续使用的学习笔记。支持 B 站与 YouTube，一次整理一个视频或一个分 P；视频下载作为辅助工具保留。

## 学习流程

1. 粘贴视频链接、分享文本或 BV 号，打开当前这一节。多分 P 课程可在目录中搜索并切换章节。
2. 检查内容来源，生成「本节目的」「关键知识」及原文支持的操作步骤。非教学内容整理主要内容，不虚构教程。
3. 点击笔记中的「查看原文」核对本次使用的字幕；有真实时间码时，可跳转原站回看对应片段。
4. 在「我的备注」记录自己的理解或实践结果，通过「我的笔记」找回内容，也可导出 Markdown。

## 本机保存与继续学习

- 笔记、字幕输入草稿、个人备注、分析范围、来源依据及阅读位置自动保存在当前浏览器的 `localStorage`。同一视频的不同分 P 独立保存，切换章节或刷新后可恢复；首页提供「继续上次」。
- 重新生成时保留原笔记，生成成功后可「查看上一版」并导出；仅保留上一版，不是完整版本历史。停止、超时或中断时保留已收到的草稿，刷新后标记为未完成。个人备注独立保存，不会被重新生成覆盖。
- 「我的笔记」支持搜索、导出和删除。删除单条后可在当前页面撤销；清除全部本机数据需要确认。
- 保存失败、空间不足或其他标签页发生冲突时会提示，当前修改可能尚未落盘；可重试保存或先导出。不会为腾出空间静默删除已有笔记、输入草稿或备注。
- 暂无账号和跨设备同步。不同浏览器、不同域名分别保存；清理网站数据或关闭无痕会话可能丢失内容。Markdown 导出包含笔记、个人备注、来源原文、原视频链接、覆盖说明及未完成提示，适合备份；目前不支持从导出文件恢复整个工作台。
- 本机保存不等于离线生成：获取视频和生成笔记需要网络，分析所需内容会经服务端发送至配置的 AI 服务；个人备注不会随生成请求发送。

## 来源、引用与覆盖范围

- 可使用自动提取、平台字幕或手动粘贴的实际字幕。手动文本优先，支持 SRT / VTT，最多 60000 字符；普通文本保留可核对原文，不生成虚构时间码。
- 有原文时，模型按段落编号生成引用。界面仅将本次来源中存在的编号显示为可操作引用；点击可查阅原文。有真实字幕时间码才提供片段回看链接，播放器是否准确跳转取决于原平台。
- 每次最多分析清洗后的 **20000 字符**。较长内容可在「本次整理范围」选择下一段；实际字符范围显示在笔记来源中。每次整理产生一个版本，不会自动合并所有片段或整套课程。
- 「已分析取得的全部文本」只表示当前取得的字幕全部进入本次分析，不代表字幕覆盖了整段视频，也不包含对全部视频画面的核验。「仅分析当前片段」会列出本次范围和总字符数。
- 自动服务只返回摘要、没有可核验原文时，明确标记「覆盖范围未确认」，不提供虚构的逐段原文或时间定位。取得原文后才可选择字符范围并生成对应引用。
- 第 2 P 及以后的分 P 使用该节的平台字幕或用户提供文本；自动视频提取暂不用于这些分 P，避免误用第 1 P 内容。缺少来源时引导补充字幕，不将标题或简介当作完整内容。

## 运行与验证

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

`npm test` 覆盖链接与分 P、代理限制、下载命令转义、流式 SSE、SRT / VTT 时间解析、分析范围与来源引用、路由的模拟上游请求，以及本机保存、版本与中断恢复。模拟请求测试不需要真实密钥，也不调用外部 AI 服务。

## 环境变量

- `BIBIGPT_API_TOKEN`：自动提取视频内容并生成摘要。保留在服务端。
- `SILICONFLOW_API_KEY`：分析实际字幕，包括平台字幕、用户粘贴文本，以及自动服务返回的原文，生成带段落引用的笔记。
- `SILICONFLOW_MODEL`：可选，默认 `Qwen/Qwen3-8B`。

默认自动模式先尝试 BibiGPT；有原文且配置了字幕分析服务时，再依据原文整理笔记。自动服务不可用时尝试平台字幕。用户指定平台字幕或粘贴文本时直接使用字幕分析服务。没有配置 AI 服务时，视频解析、本机笔记查看和下载指令仍可使用；生成区域显示配置错误及重试入口。

## 功能边界

- 链接解析支持 B 站 BV / av、分享文本、b23 短链接、分 P，以及 YouTube watch、短链接、Shorts、embed、live；链接格式可解析不代表一定能提取内容或下载。
- B 站优先通过浏览器访问官方 JSONP API；失败时尝试云端 API 和视频页面；不依赖第三方 B 站解析站。平台自身的登录、版权、区域和验证限制仍然适用。
- 「保存视频」中，B 站公开提供的单段 MP4（最多 **40 MiB**）可尝试网页下载，实际画质以平台返回为准；校验完整文件长度后才交给浏览器保存，服务端传输超时为 50 秒。
- 大文件、分段视频、YouTube 和受限视频提供本机 `yt-dlp` 下载步骤与指令，可保存视频、音频或字幕。最高画质合并及音频转换需要 FFmpeg；仍须满足原平台的访问条件。
- AI 请求支持超时、停止、失败重试。切换到其他已保存章节时，正在运行的生成仍归属于原章节；刷新或关闭页面不会让生成任务在后台继续。
- 图片和字幕代理只接受指定平台的 HTTPS 资源，不跟随资源重定向。

## 部署

通过仓库的 Vercel 集成部署。`vercel.json` 指定香港区域 `hkg1`；不要将 API 密钥提交进仓库。预览环境需要单独配置 AI 环境变量。预览域名与正式域名的本机笔记分别存储。
