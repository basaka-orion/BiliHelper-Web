# 纯文章导出与思维导图

日期：2026-10-22  
状态：本轮功能已进入实现与验收；本文记录设计定案、源码行为及待核对标准。线上发布和真实模型内容验收须以另行补充的证据为准。

## 产品决定

用户要把视频留下来，既能连续阅读完整内容，也能展开结构理解细节。默认 Markdown 应当是一篇能直接阅读、转存和复用的文章；来源依据留在独立核对入口。导图与正文共用实际来源，不能把简短摘要再包装为完整导图。

保留「完整文稿」「学习笔记」「简短摘要」三个生成模式。新导入默认完整文稿，已有文档保持原选择。结果区提供「正文 / 思维导图」两个视图，切换视图不改写正文或原文。

## Shaders 评估

本轮已按设计天团与 Shaders 技能审视 GPU 视觉能力。文字密集的文章与导图需要稳定对比度、明确层级、低干扰操作；动态光影、噪声、折射或背景粒子不会让来源关系更清楚，还会增加 WebGPU 兼容、能耗及减少动态效果的验证成本。因此不引入 Shaders 依赖与画布，使用现有 CSS、SVG 和静态反馈。导图布局动画时长设为零，图形失败仍可阅读文字大纲。

这次省略 Shaders 是针对阅读与核对任务的设计取舍，不据此改变其他项目或后续任务的视觉偏好。

## 纯文章导出规则

- 完整文稿、学习笔记、简短摘要及课程合集共用文章清理。默认保留标题、自然章节、段落、事实、论证、完整例子、数字、限制、命令与代码，不因导出再做摘要。
- 去掉来源回看链接、来源脚注、字幕时间行、章节导航时间、时间线标题和工作台生成信息。清理只识别导航装饰；会议时刻、持续时间、比例和日期等实质信息保留。
- 围栏代码、缩进代码与行内代码先保护再清理；其中看似时间码、来源链接或工作台字段的字符串保持字面内容。不能用全局删除数字或时间格式的方式实现。
- 默认文件不混入完整原文、来源元数据或个人备注。另选「导出核对稿（附原文）」时，才加入实际已取得的原文、来源说明与备注；不伪造时间码。
- 课程合集按保存的章节顺序合并已整理内容，不混入未整理章节，也不重新摘要。未完成文章或章节必须带未完成提示；纯文章格式不会把摘要变成完整文稿。
- 本轮替换旧 README 中不存在的「导出文稿（附原文）」「导出文档（附原文）」按钮名，使用界面实际提供的「导出核对稿（附原文）」。

## 导图的内容与交互

取得完整来源后自动开始逐段导图整理；完整文稿和学习笔记可与正文并行生成。简短摘要仅在其取得的来源本身完整时触发，局部来源不冒充全节。用户也可从已保存的完整原文单独生成，或先读取当前视频、当前分 P 的完整来源再生成。

模型只组织主题与层级。服务端从实际字幕构造实质内容单元，把原文细节恢复为叶子；例子、推导、条件、否定、数字及技术代码不能因为模型漏填分支而消失。模型结构不合规时按原文分组回退，界面说明部分分支使用原文组织。全寒暄来源允许空导图，但保留原文并明确没有实质内容。

图形使用固定版本 Markmap 0.18.12，随依赖本地打包，进入视图后按需载入，不依赖运行时 CDN 脚本。初始显示主题，支持分支折叠、展开全部、放大、缩小、适应视图和节点搜索。搜索可展开匹配路径并定位；选择节点显示完整文字与真实来源编号，点击依据可核对原文，有实际字幕时间码时才提供回看。

文字大纲和图形使用同一棵完整树。用户可用原生展开控件和按钮逐层阅读、查看依据；图形失败时转向文字大纲。节点内容作为纯文本安全呈现，原文中的标签、命令和特殊字符不执行为页面代码。

完成后提供 SVG 和导图 Markdown。SVG 导出临时展开全部层级并按完整内容计算范围，再恢复阅读状态；导图 Markdown 遍历完整树。两者不依赖当前视口、搜索结果或折叠分支。生成未完成时明确提示，不提供伪装完整的文件。

## 保存、恢复与边界

- 每个已完成段保存结构、来源编号与原始分段范围；范围编号包含略过寒暄的原文，不能将略过内容重新编号后与旧引用混用。
- 停止、失败或刷新保留完成前缀。刷新把运行中任务标为暂停；继续仅处理未完成范围。分段规格或结构变化时重新验证，只保留连续匹配前缀并说明重试位置，不能跨过坏段。
- 坏节点、未知来源、错序段、超过树深度/节点/文字边界，以及包含实质来源的空段，不能保存为已完成成果。存储失败明确报错，不静默丢掉导图来换取保存成功；导图单独存在的文档也属于需要保护的工作。
- 正文与导图分别保存结果。导图失败不删除已完成正文，正文失败也不删除已完成导图；二者均不等于网页关闭后仍在后台生成。
- 完整来源只表示取得的字幕均进入处理，不表示字幕覆盖了视频全部画面，也不证明 ASR 绝对准确。语音识别可能听错术语、数字、路径和代码；原文及视频仍是核对入口，结构完整不能代替事实准确性验收。

## 验收标准

下表是本轮必须核对的标准，不把设计记录当作通过证明。模拟测试、本地界面、真实模型、线上环境分别记录证据。

| 场景 | 可检查结果 |
| --- | --- |
| 三种模式、旧笔记与课程合集默认导出 | 无导航时间、来源脚注与工作台元数据；实质事实、完整例子、自然章节和代码保留。普通时刻、比例与持续时间不被误删。 |
| 技术材料导出 | 围栏、缩进和行内代码内的时间字符串、引用样式、尖括号、命令及换行保真；正文清理不越过代码边界。 |
| 核对稿单独导出 | 通过实际按钮取得来源说明、已有原文及备注；默认文章不混入附录，不伪造时间。 |
| 完整与局部来源 | 完整来源自动生成导图；局部摘要不宣称完整导图。单独生成使用当前分 P 的完整来源。 |
| 详细导图内容 | 用多组不同数字的相似案例、推导、条件、反例和代码逐项核对。所有实质单元都能找到；不能仅以节点数或关键词出现判断通过。 |
| 操作与可访问性 | 缩放、折叠、展开全部、搜索定位和节点依据均可用；键盘能进入文字大纲并核对原文。窄屏能找到工具与状态；图形失败时仍有完整文字。 |
| 完整导出 | 阅读时折叠部分分支并缩放/搜索，导出的 SVG 与导图 Markdown 仍含所有层级、细节和多行代码，导出结束恢复阅读状态。 |
| 中断与刷新 | 停止、断流、长度截断、失败和刷新均保留已完成段并显示未完成；继续不重复或跳过原文。范围错配或坏节点只保留匹配前缀。 |
| 存储保护 | 只有导图的旧文档不会被空文档清理；存储超限、坏字段或标签页冲突明确提示，当前成果可留在屏幕中。 |
| 来源与准确性 | 节点依据只指向所属原文范围；ASR 无时间码时不发明回看时间。界面与导出不将“全部取得字幕”表述为视频或识别绝对准确。 |

本轮实施代理已运行的模拟测试与类型检查由主代理整合记录；浏览器交互、文件打开结果、真实模型内容与正式发布需附相应现场证据后再标记通过。
